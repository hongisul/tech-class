의존성·빌드·데이터 전송 없는 정적 HTML/CSS/ES 모듈입니다. 기존 저장소 페이지를 변경하지 않고 독립 경로로 추가합니다. 원본 사진과 개인정보는 포함하지 않습니다.

## 실행·검증

```sh
python3 -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/circuit-lab/
node --test circuit-lab/engine.test.mjs
```

핀 두 개를 클릭/터치하거나 Tab으로 이동 후 Enter/Space로 선택합니다. Esc는 선택 취소. 전선은 작업대 또는 목록의 삭제 버튼으로 제거할 수 있습니다. 작은 화면에서는 작업대만 좌우로 스크롤합니다. 유지형 슬라이드와 마이크로 누름 상태 버튼, 예제/빈 작업대/초기화/힌트/예측 문제/회로도 보기를 제공합니다.

## 모델과 안전

전선과 닫힌 스위치 접점을 union-find로 합칩니다. 배터리 +/−가 같은 노드면 직접 단락으로 가상 전원을 차단합니다. 두 모터는 동일 저항의 부하이며 배터리 3V, Kirchhoff 노드 해석으로 각 모터 단자 전압의 차와 부호를 구합니다. 단일 전원 단자에만 연결된 회로의 전압차는 0이며 전원과 분리된 부유 회로는 0전압 기준으로 처리합니다. 저항 부하는 단락으로 오인하지 않습니다.

도선/접점의 전류 강조는 각 도선 성분의 spanning tree에서 부하 전류를 복원합니다. 이상 도선 고리에는 전류 분배가 유일하지 않으므로 유효한 한 경로만 강조할 수 있습니다. 곡선의 시각적 교차는 연결 정보에 포함하지 않습니다. 동일 핀만 전기적 접점입니다.

회전은 정성 표현입니다. 실제 모터 정격, 스위치 물리 핀 순서와 BBM은 확인되지 않았으며 실물 연결 전 전원을 분리하고 도통 검사가 필요합니다. S2는 교육용 정지 버튼이며 비상정지 안전장치가 아닙니다. 마이크로 2개의 H브리지 예제는 제외합니다.

## 회로

- 기초: BAT.+ → SL.COM–A → S1.COM–NO → M1.A, M1.B → BAT.-
- 활용: BAT.+ → SL.COM–A → S2.COM–NC → S1.COM, S1.NC → M1.A, S1.NO → M2.A, M1.B/M2.B → BAT.-. S2.NO 미사용.
- 극성: 전원 차단·정지 확인 후 모터 A/B 배선을 맞바꿉니다. 하나의 SPDT를 전환한다고 자동 반전되는 모델이 아닙니다.

## 테스트 범위

기초 8상태(S2 영향 없음), 활용 8상태, A/B 극성 교환, 직접/접점 단락, 빈 회로·끊김·한쪽 연결·부유 망, 모터 우회, 두 모터 직렬(각 1.5V)/병렬(각 3V), 중복/역순/자기 연결 방지, 100회 연결/제거/초기화, 전류 경로, 한 극에만 닿는 망. GitHub Actions에서 엔진 테스트를 실행합니다.
